# Data Visualizations

This folder contains beginner-friendly notebooks and notes focused on building strong foundations in Python data visualization using popular libraries.

## Overview

The repository is organized around three core visualization topics:

- Matplotlib
- Seaborn
- Subplots

These materials are intended for learning, practice, and experimentation with plotting techniques, chart customization, and visual storytelling using data.

## Included Topics

### Matplotlib
Focuses on:
- Basic plotting
- Line, bar, scatter, and pie charts
- Custom styling and labels
- Figure and axes customization
- Practical beginner tasks

### Seaborn
Focuses on:
- Statistical plotting
- Distribution and relationship plots
- Better default styles for data visualizations
- Visualizing patterns and trends in datasets

### Subplots
Focuses on:
- Creating multiple charts in one figure
- Layout management
- Comparing data side by side
- Building cleaner dashboard-style visuals

## How to Use

1. Open the notebook corresponding to the library you want to learn.
2. Read the handwritten notes first for conceptual understanding.
3. Work through the notebook exercises and tasks.
4. Experiment by modifying plots, datasets, and styling.

## Prerequisites

You should have:
- Python installed
- Jupyter Notebook or VS Code with Python support
- Basic understanding of Python syntax

Recommended packages:
- matplotlib
- seaborn
- pandas
- numpy

You can install them using:

```bash
pip install matplotlib seaborn pandas numpy
```

## Learning Goals

By the end of these exercises, you should be able to:
- Create common data visualizations in Python
- Customize colors, labels, legends, and axes
- Use Seaborn for cleaner statistical charts
- Build subplots for comparative analysis
- Present data more effectively in reports and notebooks

## Notes

This folder is designed as a hands-on practice space for beginners learning data visualization with Python. It is best used alongside active experimentation and small custom datasets.
